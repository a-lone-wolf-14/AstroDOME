# AstroDOME 🚀
Your Window to the Cosmos: Space Weather, Near Earth Objects, and Astronomy Picture of the Day.
This is a dynamic web platform built with React that serves as a single, intuitive dashboard for exploring essential NASA data. It utilizes the powerful NASA APIs to bring real-time Space Weather reports, track Near Earth Objects (NEOs), and showcase the stunning Astronomy Picture of the Day (APOD).

## ✨ Features
🛰️ Real-time Space Weather: View current solar activity and space environment data to understand potential impacts on Earth and satellites.

☄️ Near Earth Objects (NEOs): Access data on recently observed asteroids and comets that pass close to Earth.

🖼️ Astronomy Picture of the Day (APOD): Discover a new high-resolution astronomical image or video every day, complete with a detailed explanation.

📱 Responsive Design: A clean, mobile-first interface built for optimal viewing on any device.

## ⚙️ Quick Start (For Developers)
Follow these steps to get a local copy of the project up and running for development purposes.

Prerequisites
You will need Node.js and npm installed on your machine.

Installation
Clone the Repository:

```bash
git clone https://github.com/a-lone-wolf-14/AstroDOME.git
cd astrodome
```

Install Dependencies:

```bash
npm install
```

# Setup Environment Variables: 
Create a file named .env in the root directory and add your NASA API key.

Get your free key from: https://api.nasa.gov/
```env
REACT_APP_NASA_API_KEY=**[YOUR PERSONAL NASA API KEY]**
```
Go to the local project folder and then run the following commands:

```bash
npm install #for installing all dependencies (just to be sure)
npm run dev
```

🔗 APIs Used
All data is sourced directly from the official NASA APIs:

Space Weather Data: Utilizes the NASA Space Weather Database of Notifications and Knowledge (DONKI) API.

Near Earth Objects: Utilizes the NASA NeoWs (Near Earth Object Web Service) API.

Astronomy Picture of the Day (APOD): Utilizes the NASA APOD API.
